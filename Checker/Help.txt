Check in bulk the connection between host and the remote server recorded in
the OpenVPN config file(s) (*.ovpn).

Usage: Checker [/t[ime] period [time]] [/w[ait] timeout] [/n[umber] count]
               config1.ovpn config2.ovpn ... 

If there are multiple arguments of the same type,only the last one matters.

    /t[ime] ------- Assign process speed
                    Warning: Process too many files at once may cause crashing.
    period -------- The number of valid files to process at once.
                    0: process all files at once.
                    -1: process each file one by one.
                    Default: -1
    [time] -------- The time[s] to break after process a certain bulk of files.
                    Default: 1.0

    /w[ait] ------- Assign connection timeout
    timeout ------- The timeout[s] for every ping.
                    Default: 1.0 

    /n[umber] ----- Assign connection threshold
    count --------- The number of ping(s) per file.
                    Default: infinity (stop until the window is closed)

    /? /help --help Print this help document
