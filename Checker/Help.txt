Function 
    Check in bulk the connection between the host
    and the remote VPN server recorded in OpenVPN config file(s) (*.ovpn).

Usage 
    > Checker <arg1> <arg2> config1.ovpn config2.ovpn ... 

Options 

If there are multiple arguments of the same type,only the last one matters.

/t period [time] 

    period:
        The number of valid files to process at once.
        Set 0 to process all files at once.
        Set -1 to process each file one by one.
        Default is -1 
        Warning: Process too many files at once may cause crashing.

    time:
        The time[s] to break after process a certain bulk of files.
        If reserved,it'll reset whether it was already assigned.
        Default is 1.0 

/w timeout 

    timeout:
        The timeout[s] for every ping.
        Default is 1.0 

/n count 

    count:
        The number of ping(s) per file.
        Default is infinity,that is,stop until you close the window.
