Rename files in bulk under configured rules.

Usage: Renamer config.ini file1 file2 ... 
> Only the first config file (*.ini) will be loaded as a config.
> If you want to rename the config file as well,pass it twice.

Syntax 
    See also : Templates\Template.ini
    All keys,values and variables should be angle-bracketed and case sensitive.
    Section [Template]
        pattern     the pattern string to match filename.
        target      the target string to match filename.
    Section [Map.VariableName]
        Use <key> = <value> to configure replacement rules.
        If the captured matches <key>,it will be replaced with <value>.
        If not matched,it will keep intact.
        In addition,a null key is required to define the variable type.
        These are legal values :
            string    Capture all characters.
            alpha     Capture all letters with upper and lower case.
            digit     Capture all digits.
            float     Capture all float numbers(digits separated by a dot).
