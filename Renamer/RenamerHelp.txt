Function 
	Rename files in bulk under configured rules.

Usage 
	Renamer [config.ini] file1 file2 ... 

Grammar 

One section supported : [Replace]
Rules :
	pattern = target
Function :
	Replace every matched pattern with target.
Ps :
	Replaced patterns will be totally skipped,so borders are accepted.
