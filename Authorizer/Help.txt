Append login credentials to OpenVPN config file(s) (*.ovpn).
> It appends the assigned credential to each effective "auth-user-pass" part.

Usage: Auth [/c[redential] filename] [/dry-run] config1.ovpn config2.ovpn ...

If there are multiple arguments of the same type,only the last one matters.

    /c[redential] ----- Assign the credential file
    filename ---------- The credential file
                        Default: 'auth.txt'

    /dry-run ---------- Reject and show all changes.

    /? /help --help --- Print this help document
